# 🔔 WebPageMon — 웹페이지 변경 감시기

지정한 웹페이지를 주기적으로 확인하다가 **내용이 바뀌면 팝업으로 알려주는** 단일 HTML 도구입니다.
서버·빌드·설치가 필요 없습니다. 파일 하나(`index.html`)면 **로컬**에서도, **GitHub Pages**에서도 그대로 동작합니다.

## 주요 기능

- ✅ 여러 페이지 동시 감시 (각각 주기·방식 설정)
- ✅ 변경 감지 시 **화면 팝업 + 변경 내용 diff(− 이전 / + 현재)** 표시
- ✅ **브라우저(OS) 알림**, **소리**, **탭 제목 깜빡임** 알림 지원
- ✅ **CSS 선택자**로 특정 영역만 감시 → 광고·시계 등 오탐 최소화
- ✅ **텍스트 비교(권장)** 또는 **원본 HTML 비교** 선택
- ✅ 설정·기준값을 브라우저 `localStorage`에 저장 → 새로고침해도 유지
- ✅ CORS 프록시 선택 가능 (AllOrigins / corsproxy.io / codetabs / 직접 입력 / 없음)

## 사용 방법

### 1) 로컬에서 실행
`index.html` 파일을 더블클릭하거나 브라우저로 열면 끝입니다.

> 참고: `file://`로 열면 일부 사이트 접근이나 OS 알림이 제한될 수 있습니다.
> 가장 안정적인 로컬 실행은 간단한 정적 서버입니다.
> ```bash
> python3 -m http.server 8000
> # 브라우저에서 http://localhost:8000 접속
> ```

### 2) GitHub Pages로 실행
1. 이 저장소를 GitHub에 푸시합니다(이미 되어 있다면 생략).
2. 저장소 → **Settings → Pages** 이동
3. **Source**를 `Deploy from a branch`로 두고, 브랜치(예: `main`)와 폴더 `/(root)` 선택 후 저장
4. 잠시 뒤 `https://<사용자명>.github.io/webpagemon/` 주소에서 접속

### 3) 감시 추가
1. **감시할 페이지 URL** 입력
2. **확인 주기(초)** 설정 (기본 60초, 최소 5초)
3. (선택) **CSS 선택자**로 감시 영역 지정 — 예: `#notice`, `.board-list`, `main`
4. **+ 감시 시작** 클릭 → 첫 확인 시 기준값이 저장되고, 이후 변경되면 팝업이 뜹니다

## 동작 원리

```
주기적 fetch ──▶ (CORS 프록시) ──▶ HTML 수신
        └▶ CSS 선택자/본문 추출 ─▶ 텍스트 정규화 ─▶ 해시 비교
                                          └▶ 다르면 ⇒ 팝업·알림·소리·diff
```

이전 내용과 해시(cyrb53)를 비교해 달라졌을 때만 알립니다. 변경 시점·횟수·내용 diff를 함께 보여줍니다.

## CORS에 대해 (중요)

브라우저는 보안상 **다른 도메인의 페이지를 자바스크립트로 직접 읽는 것을 차단**합니다.
그래서 기본값으로 공개 **CORS 프록시(AllOrigins)** 를 거쳐 페이지를 가져옵니다.

- 특정 프록시가 느리거나 막히면 다른 프록시로 바꿔 보세요.
- 사내/개인 프록시가 있다면 **직접 입력**에서 `https://내프록시/?target={url}` 처럼 `{url}` 자리표시자를 넣어 사용하세요.
- 감시 대상이 **CORS를 허용**하거나 **같은 출처**라면 **프록시 없음**이 가장 빠르고 정확합니다.
- 공개 프록시에 민감한(로그인 필요) 페이지 주소를 넣지 마세요. 안정적인 운영에는 자체 프록시를 권장합니다.

## 제한 사항

- 감시는 **이 탭이 열려 있는 동안에만** 동작합니다. (브라우저가 닫히면 멈춤)
- 백그라운드 탭에서는 브라우저가 타이머 주기를 늦출 수 있습니다.
- 로그인이 필요한 페이지나 JS로 나중에 그려지는(클라이언트 렌더링) 영역은 정확히 감지되지 않을 수 있습니다.
- 24시간 무중단/탭 없이 감시하려면 서버·크론 등 백엔드 방식이 필요합니다. (이 도구의 범위 밖)
